# Build notes

Exact upstream commits, PR URLs, SDK revisions and CI artifact identifiers are in `PROVENANCE.json`. Check out those commits, initialize recursive submodules, and apply the small build-only patches in `source-patches/`. Do not substitute current upstream HEADs and expect the same result.

- ArchiveXL, Codeware, TweakXL: xmake 3.1.2, MSVC 19.44.35228 (VS 2022 toolset 14.44.35207), Windows SDK 10.0.26100.0, Windows x64 release build. Configure with `xmake f -m release -p windows -a x64 --vs=2022 -y`, then `xmake -j 6`. Pin `tiltedcore.mimalloc` to 2.2.4 using the supplied patch. The upstream `tools/dist/steps/compose-redscripts.ps1` composes script bundles; TweakXL's data and Codeware's known hashes come from their checked-out sources. Unchanged shipped resource archives are retained from the original release.
- Input Loader and Mod Settings: CMake/Ninja, same MSVC/SDK, `Release`, `CMAKE_CXX_FLAGS_RELEASE=/O2 /Ob2 /DNDEBUG /Zi`, `CMAKE_SHARED_LINKER_FLAGS_RELEASE=/DEBUG`, `CMAKE_POLICY_VERSION_MINIMUM=3.5`. Build `input_loader.dll` or `mod_settings.dll`. Input Loader uses SDK commit `8350155d491fff8e9d01ffa2aa8d1bc4617a3cf3`. Their CMake helpers inspect a locally installed, legally acquired copy of game 2.50. For script checks, point `CMAKE_REDSCRIPT_COMPILER` at the specified redscript CI CLI. Existing shipped Mod Settings scripts/assets were retained in this collection.
- RED4ext and redscript binaries were obtained from the upstream GitHub Actions runs identified in the manifest and checked against GitHub's artifact SHA-256. They were not compiled or authored by this collection. Redscript's selected artifact is the PR merge build, with its embedded revision recorded in the manifest.
- The local Quickhack Hotkeys and Equipment-EX transformations are fully contained in `Build-Mod-Compatibility.ps1`, `patch-specs.json` and `patch-code/`. They require the original mod archives from their authors and produce byte-matching tested script outputs.

The public packaging step reduces absolute PDB and diagnostic source-file paths in locally compiled DLLs to filenames without altering any executable section. This affects artifact hashes and diagnostic filenames, not program code. The executable section bytes were verified against the tested local build. The original authors' license notices are preserved and collected in `licenses/`.
