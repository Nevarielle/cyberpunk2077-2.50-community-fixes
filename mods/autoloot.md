## What this version contains

Personal 100 m automatic collection profile with automatic resumption after temporary gameplay interruptions and an option to omit line-of-sight checks. Original item-protection logic was retained.

**Dependencies:** Compatible CET. The local work used CET 1.38.0.

**Validation:** 24 behavior checks and syntax checks for 10 Lua files passed. Live gameplay validation of the AutoLoot customization was not performed by the assistant.

**Limits:** The original authors explicitly require permission to publish modifications, including publicly proposed code changes. This catalog includes no AutoLoot code, patcher or modified archive. Upstream lists 3.12.0 as of 2026-10-23; that newer version was not evaluated here.

**Installation:** Use the original author page for official downloads. This entry records personal work only; no modified AutoLoot files or patcher are supplied.
