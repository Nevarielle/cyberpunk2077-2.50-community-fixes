## What this version contains

Built the community port, regenerated its shipped script bundles from that source and included its data; pinned mimalloc 2.2.4.

**Dependencies:** Compatible RED4ext and redscript. CET is needed only by mods using CET functionality.

**Validation:** Plugin and scripts loaded; the 2.50 callback/service compatibility layer initialized.

**Limits:** Not every Codeware API or dependent mod was tested.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.

## По-русски

**Вариант:** Локальная сборка порта сообщества.

Собран порт сообщества, подготовлены скриптовые пакеты из этих исходников и данные; зафиксирован mimalloc 2.2.4.

**Зависимости:** Совместимые RED4ext и redscript. CET нужен модам, которые используют его функции.

**Проверка:** Загрузились библиотека и скрипты, инициализировалась совместимость callback/service API 2.50.

**Ограничения:** Не все функции Codeware и зависимые моды проверены.

**Установка:** Закройте игру, установите этот ZIP в Vortex как замену предыдущей версии компонента, оставьте включённой одну копию и выполните Deploy. Устанавливайте только нужный компонент и зависимости своих модов. Сохраните прежние архивы и резервную копию сохранений.
