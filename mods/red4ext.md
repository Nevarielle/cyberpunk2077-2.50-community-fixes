## What this version contains

Integrated the upstream 2.50 CI build and checked its GitHub artifact digest.

**Dependencies:** Game 2.50. It loads native plugins; redscript is needed by script mods.

**Validation:** Initialized on 2.50, loaded five native plugins and invoked script compilation.

**Limits:** Development build identified by commit, rather than a new stable version number.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.
