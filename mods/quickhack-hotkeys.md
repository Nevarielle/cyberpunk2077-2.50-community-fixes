## What this version contains

Wraps the vanilla menu lifecycle to add eight listeners, rather than replacing it, and guards input while inactive or without a player.

**Dependencies:** Original 2.3.2 ZIP, compatible RED4ext, redscript, ArchiveXL and Input Loader. Mod Settings is optional for rebinding. CET is not required.

**Validation:** Both local patchers reproduce the tested script. The user confirmed keyboard hotkeys work in gameplay.

**Limits:** Exact original hashes are required. Controller support was not separately verified. Original files are not mirrored.

**Installation:** Download the original version from its author and this separate patcher ZIP. Extract the patcher and open **Patch-Mods.html** in a current browser. Select the original ZIP, build and save the replacement ZIP, then install that generated ZIP in Vortex instead of the older mod and deploy.

## По-русски

**Вариант:** Отдельный локальный патчер.

Добавляет восемь обработчиков поверх штатной логики меню и проверку активности/наличия игрока.

**Зависимости:** Оригинальный ZIP 2.3.2, совместимые RED4ext, redscript, ArchiveXL и Input Loader. Mod Settings — для переназначения клавиш. CET не требуется.

**Проверка:** Оба локальных патчера воспроизводят проверенный скрипт. Пользователь подтвердил работу клавиш в игре.

**Ограничения:** Нужны точные файлы проверенного оригинала. Геймпад отдельно не проверялся. Оригинальные файлы не перепубликуются.

**Установка:** Скачайте оригинальную версию у автора и отдельный ZIP патчера. Распакуйте патчер, откройте **Patch-Mods.html**, выберите исходный ZIP, создайте и сохраните исправленный архив. Установите полученный ZIP в Vortex вместо старого мода и выполните Deploy.
