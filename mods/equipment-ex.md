## What this version contains

Stores the filter array in a local variable before passing it to SetData, fixing the compilation failure.

**Dependencies:** Original 1.2.9 ZIP, compatible RED4ext, redscript, ArchiveXL, Codeware and TweakXL.

**Validation:** Both patchers reproduce the tested script; compilation and its TweakXL initialization succeeded.

**Limits:** Exact original hashes are required. Wardrobe UI and all outfit operations were not exhaustively checked. Original files are not mirrored.

**Installation:** Download the original version from its author and this separate patcher ZIP. Extract the patcher and open **Patch-Mods.html** in a current browser. Select the original ZIP, build and save the replacement ZIP, then install that generated ZIP in Vortex instead of the older mod and deploy.

## По-русски

**Вариант:** Отдельный локальный патчер.

Массив фильтров сначала сохраняется в переменную, что устраняет ошибку компиляции.

**Зависимости:** Оригинальный ZIP 1.2.9, совместимые RED4ext, redscript, ArchiveXL, Codeware и TweakXL.

**Проверка:** Оба патчера воспроизводят проверенный скрипт; проверены компиляция и инициализация через TweakXL.

**Ограничения:** Нужны точные файлы проверенного оригинала. Интерфейс гардероба и все операции с одеждой полностью не проверялись. Оригинальные файлы не перепубликуются.

**Установка:** Скачайте оригинальную версию у автора и отдельный ZIP патчера. Распакуйте патчер, откройте **Patch-Mods.html**, выберите исходный ZIP, создайте и сохраните исправленный архив. Установите полученный ZIP в Vortex вместо старого мода и выполните Deploy.
