## What this version contains

Rebuilt upstream main with the compatible SDK revision. The newer source merges input XMLs before the game reads them and no longer ships stale vanilla XML copies.

**Dependencies:** Compatible RED4ext.

**Validation:** The game started and SelectHack1–8 bindings were merged and used successfully.

**Limits:** Input conflicts introduced by other mods may require separate diagnosis.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.

## По-русски

**Вариант:** Локальная пересборка исходников авторов.

Ветка main пересобрана с совместимым SDK. Новые исходники объединяют XML ввода до чтения игрой и не включают устаревшие копии игровых XML.

**Зависимости:** Совместимый RED4ext.

**Проверка:** Игра запустилась; действия SelectHack1–8 добавились и работали.

**Ограничения:** Конфликты ввода от других модов могут потребовать отдельной проверки.

**Установка:** Закройте игру, установите этот ZIP в Vortex как замену предыдущей версии компонента, оставьте включённой одну копию и выполните Deploy. Устанавливайте только нужный компонент и зависимости своих модов. Сохраните прежние архивы и резервную копию сохранений.
