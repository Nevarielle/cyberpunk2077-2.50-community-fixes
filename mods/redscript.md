## What this version contains

Integrated the verified PR 206 CI merge build, including 2.50 bundle handling and the signature-enum fix.

**Dependencies:** Game 2.50 and compatible RED4ext for the tested runtime setup.

**Validation:** The modded script bundle compiled offline and at game startup.

**Limits:** Experimental branch; this is not an unchanged official 0.5.32 release.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.
