## What this version contains

Built the community 2.50 port with the supplied SDK and mimalloc 2.2.4 build pin.

**Dependencies:** Compatible RED4ext and redscript.

**Validation:** Plugin load, archive discovery and localization initialization succeeded.

**Limits:** Journal extension and resource hot reload remain disabled in the selected port. Other features were not exhaustively tested.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.

## По-русски

**Вариант:** Локальная сборка порта сообщества.

Собран порт сообщества под 2.50 с указанным SDK и фиксацией mimalloc 2.2.4.

**Зависимости:** Совместимые RED4ext и redscript.

**Проверка:** Проверены загрузка библиотеки, обнаружение архивов и инициализация локализации.

**Ограничения:** Расширение журнала и горячая перезагрузка ресурсов пока отключены в выбранном порте. Остальные возможности полностью не проверялись.

**Установка:** Закройте игру, установите этот ZIP в Vortex как замену предыдущей версии компонента, оставьте включённой одну копию и выполните Deploy. Устанавливайте только нужный компонент и зависимости своих модов. Сохраните прежние архивы и резервную копию сохранений.
