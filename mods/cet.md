## What this version contains

Located, verified and installed the upstream 1.38.0 build. The tested CI artifact is byte-identical to the official 1.38.0 release. The compatibility port belongs to the CET project.

**Dependencies:** Compatible RED4ext; individual Lua mods may have their own dependencies.

**Validation:** Game startup, Lua initialization and drawing callbacks, TweakDB read, and RTTI binding were checked; the user confirmed the game works.

**Limits:** Upstream 1.38.0 supports game 2.50 / 3.0.88.46235, not earlier game patches. This mirror adds no CET code changes.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.
