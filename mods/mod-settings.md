## What this version contains

Built the proposed 2.50 native-layout fixes; retained the original shipped scripts and resources.

**Dependencies:** Compatible RED4ext, ArchiveXL and redscript.

**Validation:** Native plugin loaded and its scripts compiled at game startup.

**Limits:** Every settings screen and rebinding path was not exhaustively tested.

**Installation:** Close the game, install this ZIP in Vortex as the replacement for the previous version of this component, keep only one active copy, and deploy. Install only this component and the dependencies your mods require. Keep backups of previous archives and saves.

## По-русски

**Вариант:** Локальная сборка порта сообщества.

Собраны предложенные исправления структур для 2.50; сохранены оригинальные скрипты и ресурсы.

**Зависимости:** Совместимые RED4ext, ArchiveXL и redscript.

**Проверка:** Библиотека загрузилась, скрипты скомпилировались при запуске игры.

**Ограничения:** Все экраны настроек и сценарии переназначения клавиш полностью не проверялись.

**Установка:** Закройте игру, установите этот ZIP в Vortex как замену предыдущей версии компонента, оставьте включённой одну копию и выполните Deploy. Устанавливайте только нужный компонент и зависимости своих модов. Сохраните прежние архивы и резервную копию сохранений.
